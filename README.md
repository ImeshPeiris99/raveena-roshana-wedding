# Raveena & Roshana — Digital Wedding Invitation

A full-stack Next.js wedding invitation platform with premium animations, personalised guest links, RSVP, WhatsApp sharing, Supabase Auth/database/storage, Super Admin + Client Admin permissions, gallery management and a responsive admin dashboard.

Start with **FINAL-SETUP-AND-DEPLOYMENT.md**.

## Local run

```bash
npm install
npm run dev
```

## Final Supabase migration

Run:

`supabase/migrations/03-final-platform.sql`

in Supabase -> SQL Editor before using Gallery Management and editable wedding settings.
